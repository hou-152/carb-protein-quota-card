# 碳水和蛋白质配额表｜逐格对照录入版

> 来源：用户提供的 3 张截图，B站 UP 主「好人松松」视频中的配额表。  
> 用途：直接发给 Claude / Codex / Cursor，用于开发减脂/增肌网站工具。  
> 重要说明：本文件按截图逐格录入，不再用“猜规律/公式推导”替代。  
> 单位：所有数字均为 `g/kg体重`。

---

## 0. 数字含义

### 有力量训练版本

格式：

```text
训练日碳水 / 休息日碳水 / 每日蛋白质
```

例如：

```text
2.6/2.0/1.4
```

意思是：

```text
训练日碳水 = 2.6 × 体重kg
休息日碳水 = 2.0 × 体重kg
每日蛋白质 = 1.4 × 体重kg
```

---

### 无力量训练版本

格式：

```text
每日碳水 / 每日蛋白质
```

例如：

```text
2.4/1.0
```

意思是：

```text
每日碳水 = 2.4 × 体重kg
每日蛋白质 = 1.0 × 体重kg
```

# 7. 给 Claude 的开发要求

请基于以上逐格数据开发一个网页工具。

## 用户输入

```text
性别：男 / 女
训练状态：有力量训练 / 无力量训练
目标：减脂 / 增肌
身高：按对应性别的表格档位选择
体重：按对应性别的表格档位选择，或输入后自动匹配最近档位
```

## 输出逻辑

### 有力量训练

输出：

```text
训练日碳水 = 训练日碳水系数 × 体重
休息日碳水 = 休息日碳水系数 × 体重
每日蛋白质 = 蛋白质系数 × 体重
```

### 无力量训练

输出：

```text
每日碳水 = 每日碳水系数 × 体重
每日蛋白质 = 蛋白质系数 × 体重
```

## 特殊逻辑

```text
1. 如果单元格是 "-"，提示：该身高体重组合不在当前截图表格范围内。
2. 无力量训练只有减脂表，没有增肌表。
3. 不要用公式拟合替代查表。
4. 必须按表格逐格查询。
5. 数据结构建议用 JSON / object 保存，不要写一堆 if else。
```
