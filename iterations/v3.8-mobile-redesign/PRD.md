# v3.8 Mobile Redesign PRD

## 背景

v3.7 的桌面端已形成更明确的工具台视觉，但手机端仍然像把桌面仪表盘压窄：首屏先看到长表单，结果被推到下方，顶部导航占空间，产品文档和 Q&A 仍是桌面式 tab。用户明确反馈手机版“惨不忍睹”，需要按 mobile-first 重新设计。

## 设计读取

这是一个会反复打开的移动工具，不是桌面页面的缩小版。手机端应该优先让用户立刻看到“今天怎么吃”，再允许进入参数调整、文档和问答。

## 目标

- 手机首屏优先显示核心结果，不再被长表单占满。
- 输入区改成身体 / 训练 / 有氧三组折叠控件。
- 手机端使用底部固定导航，替代顶部多按钮导航。
- 产品文档在手机端切换为下拉选择，避免横向 tab 挤压。
- Q&A、Changelog 保持折叠阅读，不一次性铺满。
- 桌面布局保持 v3.7 的工具台结构，不做大改。

## 范围

- 修改 `App.tsx`：新增移动端底部导航。
- 修改 `InputPanel.tsx`：参数按三组拆分，移动端默认只展开身体组，桌面全部展开。
- 修改 `ResultCard.tsx`：移动端新增主结果摘要；产品文档增加移动端 select。
- 修改 `global.css`：新增 mobile app shell、底部导航、折叠表单、移动结果卡和文档阅读样式。

## 不做

- 不改计算逻辑、查表逻辑、Q&A 数据、Changelog 数据。
- 不引入 UI 框架或动画库。
- 不改 CloudBase / GitHub / Cloudflare 部署结构。
- 不做登录、保存记录或每日打卡。

## 验收

- `npm run verify` 通过。
- 390px、430px、768px 移动端无横向溢出。
- 390px 首屏能看到工具名、核心结果和“调整参数”入口。
- 表单在手机端分组折叠，身体组默认展开，训练和有氧默认折叠。
- 产品文档在手机端通过 select 切换，不再展示拥挤 tab。
- GitHub Pages 和 Cloudflare Pages 都部署到最新构建。
