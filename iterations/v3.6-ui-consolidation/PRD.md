# v3.6 UI Consolidation PRD

## 背景

v3.5 之后，本地预览、GitHub Pages 和 CloudBase 曾出现不同构建产物，导致页面视觉在浅色卡片风格和冷黑器械感之间来回变化。用户需要一个稳定基准，而不是重新发明一套新风格。

## 目标

- 恢复并固定冷黑器械感作为当前唯一视觉基线。
- 不重做产品信息架构，不新增大功能。
- 保留 v3.5 的动态产品文档、Changelog、真实 Q&A、有氧碳水并入和输入区流畅度修复。
- 让本地、GitHub Pages、CloudBase 使用同一套构建产物。

## 范围

- 恢复深色视觉变量、面板、按钮、图表、文档、Q&A 和表格样式。
- 修复当前组件类名与旧深色 CSS 的差异。
- 保持 Changelog 版本组默认折叠。
- 保持 Q&A 默认全部折叠。
- 保持数字输入为 0 时聚焦自动全选。

## 不做

- 不做全新品牌视觉。
- 不改查表、BMI、热量、有氧碳水、分餐和 Q&A 数据逻辑。
- 不新增饮食记录或每日剩余额度功能。

## 验收

- `npm run typecheck` 通过。
- `npm run verify:data` 通过。
- `npm run build` 通过。
- 本地预览和线上页面加载同一新包。
- 首屏保持工具感，输入区、今日结果、周期判断、产品文档、Q&A 都使用同一深色视觉语言。
