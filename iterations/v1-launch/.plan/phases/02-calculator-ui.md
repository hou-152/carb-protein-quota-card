# Phase 02 — Calculator UI

**Status**: `not started`
**目标**: 实现用户输入、查表计算、结果卡和不可用状态提示。
**前置**: Phase 01 完成。

## 验收判据

- 用户可以选择性别、训练状态、目标、身高和体重。
- 有力量训练时，结果卡显示训练日碳水、休息日碳水、每日蛋白质。
- 无力量训练时，结果卡显示每日碳水、每日蛋白质。
- `-` 单元格显示“当前表格范围外”，不猜值。
- “无力量训练 + 增肌”显示不支持。
- 结果全部四舍五入为整数克。
- “复制结果”按钮复制纯文本摘要，不生成图片。
